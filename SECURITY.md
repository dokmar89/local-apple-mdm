# Bezpečnost

Bezpečnostní chyby hlaste soukromě přes funkci **Report a vulnerability** na GitHubu. Veřejný report nesmí obsahovat tokeny, certifikáty, privátní klíče, sériová čísla, UDID ani zachycené profily.

Tento projekt je určen pro vlastní laboratorní zařízení a výuku. Před produkčním použitím vyžaduje samostatný bezpečnostní návrh, řízení přístupu, rotaci klíčů, zálohování a provozní dohled.
