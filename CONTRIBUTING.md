# Příspěvky do projektu

Projekt je laboratorní implementace Apple MDM. Změny protokolu doplňte odkazem na veřejnou dokumentaci nebo přesným odůvodněním a testem.

Před odesláním změny spusťte:

```sh
npm ci
npm run typecheck
npm test
```

Do repozitáře nikdy nevkládejte `.env`, databázi, APNs klíče, certifikáty, profily zařízení ani zachycené požadavky.
